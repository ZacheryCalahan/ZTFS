Usage:
    ./ztfs_util {command} [arguments...]

    commands:
        -c <disk image> <block size> <file system size>
            Create ztfs image file

            arguments:
                <disk image> Name of the image to create
                <block size> Block size in bytes
                <file system size> Size of the file system in bytes
        
        -p <disk image> 
            Display current info about an image file

            arguments:
                <disk image> Path to the image

        -e <disk image> <path>
            Display the information of the entry at the path.

            arguments:
                <disk image> Path to the image
                <path> Path to the entry

        -t <disk image>
            Display the current directory layout in tree format

            arguments:
                <disk image> Path to the image

        -m <disk image> <path>
            Make a new directory with a given path
            
            arguments:
                <disk image> Path to the image
                <path> Path to new directory, where last item in path is 
                    directory to create (ie. `/home/dir`)
